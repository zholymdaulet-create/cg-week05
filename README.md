# 5-апта — Индекс буфері (EBO), примитив түрлері

`main.cpp`-ті репозиторийдегі файлдың орнына қой: `cmake --build build && ./build/bin/cg`

> Uniform аты `uOffset` деп алынды. 4-аптада басқа ат қойған болсаң (мысалы `offset`), шейдердегі және `glGetUniformLocation`-дағы атты өзіңдікіне ауыстыр.

## Тапсырма ауыстырғыштары (файл басында)
```cpp
const bool TASK1_BROKEN_INDICES = false;  // 1: {0,1,2}, саны 3
const bool TASK2_PENTAGON       = false;  // 2: бесбұрыш
const bool TASK3_TWO_OBJECTS    = true;   // 3: екі объект
```
Барлығы `false` болса — базалық бөлім: бір төртбұрыш шеңбер бойымен қозғалады.

## Пернелер (қосымша)
`1` TRIANGLES · `2` LINE_LOOP · `3` LINE_STRIP · `4` POINTS (`glPointSize(10)`) · `Tab` wireframe

## Не жасалды
- **Базалық:** 4 вершина (6 емес), 6 индекс, EBO VAO байланып тұрғанда жасалған, `glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, 0)`, `glDeleteBuffers(1, &ebo)`. `glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, 0)` әдейі жазылмаған.
- **1.** Индекс `{0, 1, 2}`, саны 3 — бір үшбұрыш.
- **2.** Бесбұрыш: вершиналар `cos/sin(бұрыш) * 0.3` арқылы есептеледі, индекстер `0,1,2, 0,2,3, 0,3,4`.
- **3.** Бір VAO, екі `glUniform2f` + `glDrawElements` жұбы.
- **Қосымша:** примитив түрлері, Tab wireframe, `glPointSize(10)`, екі объект қарама-қарсы бағытта айналады.

## Қорғауға жауаптар
**1. Қай үшбұрыш жоғалды? Неге? Вершина деректері өзгерді ме?**
Индекстер `{0,1,2}` = оң жоғарғы → оң төменгі → сол төменгі. Яғни төртбұрыштың **оң-төменгі жартысы** қалады, ал **сол-жоғарғы жартысы** (3-вершина — сол жоғарғы бұрыш) жоғалды, өйткені 3-индекс енді ешқайда қолданылмайды. Вершина деректері (VBO) **өзгерген жоқ** — 4 вершина әлі GPU-да тұр; индекс тек олардың қайсысын, қандай ретпен алу керегін айтады.

**2. Ортақ вершина қайсы?** 0-вершина — үш үшбұрыштың бәрінде бар (0,1,2 / 0,2,3 / 0,3,4).
**GL_TRIANGLE_FAN қолдансаң, индекс саны?** **5** — `0,1,2,3,4`. Fan-да бірінші вершина орталық, әр келесі вершина алдыңғымен бірге жаңа үшбұрыш жасайды: n вершина → n−2 үшбұрыш (5 → 3).

**3. Екеуіне қанша байт дерек жіберілді? Геометрия қайта жіберілді ме?**
Геометрия **бір рет**, инициализацияда жіберілді:
- VBO: 4 вершина × 6 float × 4 байт = **96 байт**
- EBO: 6 индекс × 4 байт (`unsigned int`) = **24 байт**
- Барлығы **120 байт**.

Екінші объект үшін геометрия **қайта жіберілмейді** — сол VAO/VBO/EBO қайта қолданылады. Әр сызу алдында тек uniform өзгереді: `glUniform2f` = 2 float = 8 байт.

**Қосымша: 6 индекстен (0,1,3,1,2,3) әр примитив не шығарады?**
- `GL_LINE_STRIP` — 0→1→3→1→2→3 тізбегі, тұйықталмайды.
- `GL_LINE_LOOP` — сол тізбек, соңынан 3→0 жалғанады.
- `GL_POINTS` — әр индекс бір нүкте, нәтижесінде 4 бұрышта 4 нүкте көрінеді (1 мен 3 екі рет сызылады, бірақ бір жерге түседі).
